# Game E-commerce Website: Feature Cost Breakdown

## Project Overview
This project outlines the features and development costs for a custom gaming e-commerce website offering PC and PS5 games for both permanent purchase and time-based rentals.

## Feature & Cost Breakdown

| Module | Feature Details | Estimated Cost |
| :--- | :--- | :--- |
| **1. Storefront & Product Display** | • **Dual Categories:** Dedicated UI sections for PC and PS5 games.<br>• **Price Variations:** System to handle dynamic pricing based on game editions or variations. | ₹600 |
| **2. Purchase & Rental System** | • **Permanent Buy Option:** Standard checkout for permanent game purchases.<br>• **Time-Based Renting:** Logic to allow users to rent games for specific durations. | ₹800 |
| **3. Proofs Section** | • **Public Proofs Gallery:** A dedicated section for customers to view uploaded proofs of successful transactions. | ₹400 |
| **4. Admin Panel: Catalog Management** | • **Full Customization:** Add, edit, or delete games and manage inventory.<br>• **Variant Management:** Update variant prices and details seamlessly. | ₹700 |
| **5. Admin Panel: Rent Tracking & Proofs** | • **Rent Tracking Dashboard:** Monitor active rentals and track expiry times.<br>• **Proofs Upload Interface:** Simple interface for the admin to upload screenshots/images directly to the public Proofs section. | ₹700 |

## Terms and Conditions

1. **Payment Schedule:** 15% non-refundable upfront payment to commence work, and the remaining 85% upon project completion and deployment.
2. **Timeline:** The estimated time for completion is 1 to 2 weeks from the project start date.
3. **Revisions:** The cost includes up to 2 minor UI revisions. Major structural or feature changes requested after development has begun will incur additional charges.
4. **Asset Provision:** The client must provide any specific branding assets (logos, color schemes) prior to the start of development.
5. **Scope Change:** Any new features requested that are not mentioned in this document will cost extra.
6. **Post-Launch Support:** Free bug fixes and support for 15 days after the project is completed.
